# Accessibility

All functions must be keyboard operable. Icon-only controls need accessible names, sliders need meaningful names and values, mute state must be announced, and focus must remain visible.

State cannot rely on color alone. The interface must support high contrast, scaling, screen readers, and reduced motion where available. Test at 100%, 125%, 150%, and 200% scaling.

Physical controllers are an accessibility surface as well as a convenience. Avoid claiming formal accessibility conformance until it has been tested.

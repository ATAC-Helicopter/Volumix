# UI system

The default mixer is a narrow vertical utility, approximately 360 pixels wide with a 320-pixel minimum. It prioritizes output and logical applications, using the spacing scale 4, 8, 12, 16, 24, and 32.

System, light, and dark themes are required. The visual tone is calm, compact, readable, and tactile. Avoid graph-editor terminology, neon gamer styling, excessive cards, and faux studio-console decoration.

Application rows eventually contain icon, name, volume, slider, mute, and contextual actions. PID and PipeWire node identifiers belong only in diagnostics.
